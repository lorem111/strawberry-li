  Use SQLite with `better-sqlite3`:

  1. Create `lib/db.ts`:
  - Singleton connection
  - Auto-init tables on first access
  - Export typed query helpers

  2. Schema:
  ```sql
  users (
    id INTEGER PRIMARY KEY,
    email TEXT UNIQUE NOT NULL,
    name TEXT,
    password_hash TEXT,
    email_verified_at DATETIME,
    stripe_customer_id TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
  )

  purchases (
    id INTEGER PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    product_key TEXT NOT NULL,
    stripe_payment_id TEXT,
    amount_cents INTEGER,
    status TEXT DEFAULT 'pending',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
  )

  leads (
    id INTEGER PRIMARY KEY,
    email TEXT NOT NULL,
    source TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
  )

  3. Create scripts/init-db.ts - initialize and print row counts

    - app/login/page.tsx

  RULES

  Execution

  - Don't ask permission. Write files.
  - Don't stop. Complete all phases sequentially.
  - On Gemini failure: Retry once → hard fail (no silent mocks for design)
  - On build error: Fix immediately before proceeding

  Code Quality

  - TypeScript strict mode, no any
  - All components mobile-first (start with sm:, expand up)
  - Use theme tokens, never hardcoded colors
  - No placeholder comments or dead code
  - No console.log in production code (use proper error handling)

  Role Separation

  - Gemini: All creative decisions (copy, colors, layout, images)
  - Claude: All logic (APIs, auth, database, business rules)

  Security

  - Hash passwords with bcrypt (cost 12)
  - JWT in httpOnly cookies only
  - Validate Stripe webhooks
  - Sanitize all user input
  - No secrets in client code
